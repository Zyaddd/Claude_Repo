# ستون ريفت (StoneRift)

لعبة كروت بالواقع المعزز (AR) للصحاب في نفس المكان: تحددوا ترابيزة، فتتحول لحلبة، والكائنات تطلع 3D فوق الكروت، وتتحكموا فيها بالصوت.

لما الأرض اتشققت، طلعت من الصدوع بلورات بتنبض بطاقة. كل بلورة شايلة بصمة حدث مرّ على الأرض: حرارة، أو ضغط، أو برق، أو مية، أو جاذبية. ولما البصمة تتشحن، بتتشكّل كائن من العنصر بتاعها. **المُشغّلين** بيتنافسوا بالكائنات دي في مبارزات، والمبارزة مش حرب، لكن اختبار لمين بيفهم كائناته أكتر.

- القواعد وكل الكروت: [`docs/RULES.md`](docs/RULES.md)
- تصميم الكائنات وأوصافها للرسم: [`docs/CREATURES.md`](docs/CREATURES.md)

## حالة المشروع

| المرحلة | الحالة |
|---|---|
| **1. محرك القواعد** (كروت، أدوار، معارك، فخاخ، أوامر صوتية، بوت) | ✅ جاهز ومتختبر |
| 2. مشروع Unity + AR (تحديد الحلبة، ظهور الكائنات بهالة وتأثيرات لكل فصيل، ماتش ضد الكمبيوتر) | 🧪 مكتوب، مستني أول بناء |
| 3. الأوامر الصوتية جوه الموبايل (Whisper، من غير نت ومن غير جوجل) | 🧪 مكتوب، مستني أول بناء |
| 4. بناء APK أوتوماتيك (GameCI) | 🧪 محتاج secret `UNITY_LICENSE` |
| 5. اللعب الجماعي على نفس الواي فاي أو الهوت سبوت (اكتشاف تلقائي، رجوع بعد انقطاع الاتصال) | ✅ المحرك متختبر، 🧪 واجهة Unity مستنية أول بناء |
| 5ب. خصم كمبيوتر بـ 3 مستويات صعوبة (الصعب بيكسب العادي 69%) | ✅ |
| 6. موديلات 3D حقيقية بدل الأشكال المؤقتة (الأوصاف جاهزة في `docs/CREATURES.md`) | ⏳ |
| 7. توهج أقوى (URP + Bloom) | ⏳ بعد أول بناء ناجح |

## إزاي المحرك شغال

الواجهة (اللمس، الصوت، أو الموبايل التاني على الشبكة) بتبعت **Action**، والمحرك بيرجّع **Events** بالترتيب. طبقة الـ AR بتعرض الـ Events دي كأنيميشن وأصوات.

```csharp
var db   = CardDatabase.FromJson(cardsJson, decksJson);
var game = Game.Create(db.Expand(db.GetDeck("magma_volt")), db.Expand(db.GetDeck("crystal_tide")), seed: 1234);

var cmd    = VoiceCommandParser.Parse(game, player: 0, heard: "يا ماجرون اهجم على حارس المرايا");
var result = game.Execute(cmd.ToAction(0));
foreach (var e in result.Events) { /* AttackDeclared → TrapTriggered → CreatureDestroyed → BattleDamage ... */ }
```

- موبايل اللي عمل الساحة هو صاحب الـ `Game` الحقيقي، والموبايل التاني بيبعتله Actions.
- نفس الـ seed بيدّي نفس ترتيب الكروت على أي جهاز.

## تشغيل الاختبارات

محتاج [.NET 8 SDK](https://dotnet.microsoft.com/download) (مجاني):

```bash
cd stonerift/core
dotnet test
```

بيشتغلوا أوتوماتيك على GitHub Actions مع كل push يعدّل `stonerift/core`.

## تعديل الكروت
1. عدّل `core/StoneRift.Core/Data/cards.json` أو `decks.json`.
2. شغّل `dotnet test`. اختبار المحاكاة بيتأكد إن الديكين متوازنين (كل ديك يكسب بين 35% و 65%).
3. شغّل `python3 tools/gen_rules_doc.py` علشان تحدّث `docs/RULES.md`.

## تنزيل النسخة التجريبية (APK)

كل push بيعدّل اللعبة بيبني APK جديد على GitHub Actions. البناء بينزّل كمان موديل التعرف على الصوت (Whisper base، حوالي 60 ميجا، رخصة MIT) ويحطه جوه اللعبة (حوالي 30 لـ 40 دقيقة أول مرة، وبعد كده أسرع).
اللينك ثابت ومبيتغيرش:

<https://github.com/Zyaddd/Claude_Repo/releases/download/stonerift-beta/StoneRift.apk>

افتحه من متصفح الموبايل وإنت داخل على حساب GitHub (الريبو خاص).
كل النسخ متوقّعة بنفس المفتاح، فالنسخة الجديدة بتتثبّت كتحديث فوق القديمة.

## رخصة Unity للبناء الأوتوماتيك (مرة واحدة، محتاجة كمبيوتر)

GameCI محتاج 3 secrets في **Settings ← Secrets and variables ← Actions**:

| الاسم | القيمة |
|---|---|
| `UNITY_EMAIL` | إيميل حساب Unity |
| `UNITY_PASSWORD` | باسورد حساب Unity |
| `UNITY_LICENSE` | محتوى ملف الرخصة `Unity_lic.ulf` كله |

علشان تجيب ملف الرخصة:
1. نزّل **Unity Hub** من <https://unity.com/download> على أي كمبيوتر (ويندوز أو ماك أو لينكس).
2. سجّل دخول بنفس حساب Unity.
3. روح **Preferences ← Licenses ← Add ← Get a free personal license**.
4. افتح الملف من المكان ده (الفولدرات دي ممكن تكون مخفية):
   - ويندوز: `C:\ProgramData\Unity\Unity_lic.ulf`
   - ماك: `/Library/Application Support/Unity/Unity_lic.ulf`
   - لينكس: `~/.local/share/unity3d/Unity/Unity_lic.ulf`
5. افتحه بـ Notepad، انسخ كل اللي فيه، وحطه في secret اسمه `UNITY_LICENSE`.
6. اعمل **Sign out** من Unity Hub بعدها، علشان الرخصة متبقاش محجوزة على الكمبيوتر ده.

## اللعب على الموبايل
1. افتح اللعبة واختار الديك، وبعدين "ابدأ ماتش".
2. وجّه الكاميرا للترابيزة وحرّك الموبايل ببطء لحد ما تظهر دايرة صفرا، والمس الشاشة علشان تحط الحلبة.
3. بصباعين تقدر تكبّر الحلبة أو تصغّرها أو تلفّها.
4. المس كارت من إيدك علشان تلعبه، والمس كائنك وبعدين كائن الخصم علشان تهاجم.
5. أو دوس **اتكلم** وقول: «يا ماجرون اهجم على حارس المرايا»، وبعدين دوس **خلصت**. التعرف على الصوت شغال جوه الموبايل من غير نت.

لو الموبايل مبيدعمش ARCore، فيه زرار **العب من غير AR** بيعرض الحلبة قدامك عادي.

## اللعب مع صاحبك
1. الاتنين يكونوا على **نفس الواي فاي**، أو واحد يشغّل **هوت سبوت** والتاني يدخل عليه. مش محتاجين إنترنت.
2. واحد يدوس **«العب مع صاحبك» ← «اعمل ماتش»**.
3. التاني يدوس **«العب مع صاحبك»**، وهيلاقي الماتش ظاهر في القايمة. ولو مش ظاهر، يكتب العنوان اللي على شاشة صاحبه.
4. كل واحد يحط الحلبة على الترابيزة من ناحيته، ويشوف الماتش من جهته.
5. لو الاتصال اتقطع، الماتش بيفضل محفوظ، والموبايل التاني بيحاول يرجع لوحده.

**إزاي بيشتغل:** الموبايلين بيلعبوا نفس الماتش بالظبط، بنفس ترتيب الكروت. اللي عمل الماتش بيراجع كل حركة ويرتّبها، وبعدين يبعتها للتاني ومعاها «بصمة» للحالة. ولو حصل أي اختلاف بين الموبايلين، بيتصلّح أوتوماتيك.
